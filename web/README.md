# 🎓 Sigma Web Dev Teaching Assistant

A **RAG-powered (Retrieval-Augmented Generation)** teaching assistant for the [Sigma Web Development Course](https://www.youtube.com/playlist?list=PLu0W_9lII9agq5TrH9XLIKQvv0iaF2X3w) by CodeWithHarry. Ask any question about HTML, CSS, JavaScript, Flexbox, Grid, and more — and get answers grounded in the actual video content with precise timestamps.

---

## ✨ Features

- 🔍 **Semantic Search via Pinecone** — Vector similarity search over 1,727 subtitle chunks from the course videos
- 🤖 **Gemini AI Generation** — Answers generated by Gemini using retrieved video content as context
- 🕐 **Timestamp Citations** — Every answer references specific videos and timestamps (e.g. `Video #42 at 14:10`)
- ⚡ **Cascading Fallback** — Pinecone → In-memory cosine similarity (if Pinecone is unavailable)
- 🚀 **Deployed on Vercel** — Auto-deploys on every push to `main`

## 🚀 Getting Started

### Prerequisites

- Node.js 22+ (`export PATH="/opt/homebrew/opt/node@22/bin:$PATH"`)
- A [Gemini API key](https://aistudio.google.com/)
- A [Pinecone API key](https://www.pinecone.io/) with an index named `sigmalearn` (dimensions: 1024, metric: cosine)

### 1. Install dependencies

```bash
cd web
npm install
```

### 2. Set up environment variables

Create `web/.env.local`:

```env
GEMINI_API_KEY=your_gemini_api_key
PINECONE_API_KEY=your_pinecone_api_key
PINECONE_INDEX=sigmalearn
```

### 3. Upload embeddings to Pinecone (one-time)

```bash
cd web
export PATH="/opt/homebrew/opt/node@22/bin:$PATH"
node upload_to_pinecone.mjs
```

This uploads all 1,727 pre-computed subtitle chunks to your Pinecone index.

### 4. Run the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to use the assistant.

## 🔄 RAG Pipeline

```
User Question
     │
     ▼
[Gemini Embedding]  →  1024-dim query vector
     │
     ▼
[Pinecone Search]   →  Top-5 semantically similar subtitle chunks
     │  (fallback: in-memory cosine similarity)
     ▼
[Gemini Generation] →  Answer with video + timestamp citations
     │
     ▼
Response to User
```

## 🐳 Docker

Run the app locally in a container (no Node.js install required):

```bash
cd web

# Build and start
docker compose up --build
```

Pass API keys via environment:

```bash
GEMINI_API_KEY=your_key \
PINECONE_API_KEY=your_key \
PINECONE_INDEX=sigmalearn \
docker compose up --build
```

Or create a `.env` file in `web/` and run:

```bash
docker compose --env-file .env.local up --build
```

App will be available at **http://localhost:3000**.

## ☁️ Deployment (Vercel)

The app auto-deploys on every push to `main`. Make sure these environment variables are set in **Vercel → Project → Settings → Environment Variables**:

```
GEMINI_API_KEY
PINECONE_API_KEY
PINECONE_INDEX
```

> **Note:** `embeddings.json` is committed to the repo and serves as the in-memory fallback. Pinecone is the primary search backend and must be seeded separately using `upload_to_pinecone.mjs`.

## 📊 Data Pipeline (Offline)

The subtitle chunks were generated from the course videos using:

1. `downloading_videos.py` — Downloads videos
2. `video_to_mp3.py` — Converts to audio
3. `mp3_to_json.py` — Transcribes audio to JSON subtitles
4. `reembed_from_jsons.py` — Generates Gemini embeddings
5. `merge_chunks.py` — Merges and exports `embeddings.json`
6. `upload_to_pinecone.mjs` — Seeds Pinecone index
